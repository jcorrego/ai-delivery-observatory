# AI Delivery Observatory

A portable tool for organizations to compare engineering delivery, collaboration,
AI usage, and historical work capacity. It uses explicit assumptions and keeps
human activity separate from automation.

The first implementation is developed on the
[`feature/reference-tool` branch](https://github.com/jcorrego/ai-delivery-observatory/tree/feature/reference-tool).
Its examples are synthetic. No employer datasets or application source are included.
