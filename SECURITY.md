# Security

For a security issue, do not attach credentials, organization records, or private
reports to a public issue. Use GitHub's private vulnerability reporting for this
repository when available. If it is unavailable, report a minimal synthetic
reproduction and request a private contact route before sharing sensitive details.

The local server binds only to loopback. It is not an enterprise hosting service.
Static exports embed all their report data; filters do not enforce access control.
See [deployment guidance](docs/deployment.md) for required shared-deployment controls.
